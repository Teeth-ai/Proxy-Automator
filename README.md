Proxy Automator Pro 🚀

An automated GUI tool that instantly deploys a secure, cloud-based proxy server using your free GitHub Codespaces quota. Built with Python and CustomTkinter, this launcher handles authentication, repository setup, and SSH tunneling with a single click.

 ✨ Features
* **1-Click Authentication:** Automatically links securely with your GitHub account via standard device login.
* **Auto-Setup:** Initializes the required cloud infrastructure (proxy-auto` repo) automatically.
* **Anti-Detect Stealth Mode:** Injects custom Chromium flags to block WebRTC leaks and hide your real IP.
* **Standalone Executable:** No Python installation required. Just download and run!

 📥 Installation
1. Go to the [Releases](../../releases) tab on the right.
2. Download the latest `proxy_launcher.exe`.
3. Run the application.

 🛠️ Quick Setup Guide
1. Go to the **Settings** tab.
2. Click **1. Connect GitHub Account**. A terminal will open. Follow the prompts (Select GitHub.com -> HTTPS -> Yes -> Login with a web browser) and paste the code into your browser.
3. Click **2. Auto-Setup Repository** and wait for the "Success" popup.
4. Switch to the **Dashboard** tab.
5. Click **Deploy Server** and wait for the environment to build.
6. Click **Connect & Launch Browser**. The app will launch Brave Browser routed through your new secure Singapore/US proxy!

 ⚠️ Disclaimer
This tool uses GitHub Codespaces. Every free GitHub account includes up to 120 core-hours per month of free Codespace usage. Be sure to click **Destroy Instance** when you are done to save your quota!
